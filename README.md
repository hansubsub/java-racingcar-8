# java-racingcar-precourse
## 구현할 기능 목록✔️

---

### Car

- [ ]  자동차 생성 및 이름 부여
    - [ ]  자동차 이름은 5자 이하, 중복 불가, 빈칸 불가
    - [ ]  위반시 오류 illegalArgumentException

### RaceManager

- [ ]  모든 자동차 생성
- [ ]  경주에 참여하는 자동차가 둘 이상인지 확인
- [ ]  경주 시작
- [ ]  경주 종료 및 우승자 판별

### Race: 라운드마다 자동차 이동

- [ ]  경주 생성
- [ ]  각 자동차에 0~9 랜덤 값 부여
    - [ ]  4이상인 자동차는 전진

### Round

- [ ]  시도할 횟수(라운드 수) 생성
    - [ ]  숫자로 변환
- [ ]  라운드 반복

### Input

- [ ]  `경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)`
- [ ]  `시도할 횟수는 몇 회인가요?`

### Output

- [ ]  `실행 결과`

     `이름1:`

     `이름2:`

     `…`

- [ ]  `최종 우승자 :`
